# 🌊 모아나의 항해 (Moana Voyage)

영화 〈모아나〉와 〈모아나 2〉를 바탕으로 만든 **비상업용 3D 항해 팬 게임**입니다.
모아나가 되어 배를 몰고 넓은 바다를 건너, 마우이와 함께 테 피티의 심장을 돌려주세요.
아이패드(터치)와 컴퓨터(키보드) 모두에서 브라우저로 바로 즐길 수 있습니다.

![icon](icons/icon.svg)

## 🎮 웹에서 바로 하기

설치 없이 아이패드나 컴퓨터 브라우저에서 이 주소를 열면 됩니다.

**https://merrypapa.github.io/moana-voyage/**

`main` 브랜치에 푸시하면 자동으로 다시 배포됩니다.

## 내 컴퓨터에서 실행하기

Node.js 18 이상이 필요합니다. 설치할 패키지는 없습니다.

```bash
npm start
```

- 컴퓨터: 브라우저에서 `http://localhost:8080`
- 아이패드: 같은 Wi-Fi에서 터미널에 표시되는 `http://192.168.x.x:8080` 주소로 접속
  - Safari 공유 버튼 → "홈 화면에 추가"를 누르면 전체 화면 앱처럼 쓸 수 있어요.

빌드 과정이 없는 정적 웹 앱이라 GitHub Pages 같은 정적 호스팅에 그대로 올려도 동작합니다.

## 👫 2인 플레이 (모아나 + 마우이)

두 기기(아이패드 2대, 또는 아이패드 + 컴퓨터)로 같은 바다에서 함께 놀 수 있어요.

1. 두 기기 모두 게임 주소를 엽니다.
2. **모아나**: 처음 화면의 [👫 함께 하기] → [방 만들기] → 화면에 나온 **방 번호 4자리**를 친구에게 알려 줍니다 → [새로 시작] 또는 [이어하기]
3. **마우이**: [👫 함께 하기] → [참가하기] → 방 번호 입력 → [참가하기]

- 모아나가 먼저 시작하고 마우이가 나중에 들어와도 돼요. 마우이가 없을 때는 컴퓨터가 마우이를 조종해요.
- 모아나의 기기가 게임을 계산하고 저장해요. 마우이는 모아나의 게임에 들어가는 방식이에요.
- 두 기기 모두 인터넷이 필요해요(처음 서로를 찾을 때 PeerJS 무료 연결 도우미를 사용).
- 인터넷 없이 같은 Wi-Fi에서만 하려면: 컴퓨터에서 `npm install && npm run peer-server`를 실행하고, 두 기기 모두 주소 뒤에 표시된 `?peer=IP:9000`을 붙여서 접속하세요.

## 무엇을 할 수 있나요?

- ⛵ **항해**: 배 뒤쪽의 키를 잡고 돛을 올려 바다를 누비기 (바람을 등지면 더 빨라요)
- 🌊 **바다가 구해줘요**: 물에 빠지면 바다가 물기둥으로 들어 올려 배 위에 내려줘요
- 🐔 **헤이헤이**: 배 위의 네모 상자에 스스로 들어갔다 나왔다 해요. 안아서 넣고 꺼낼 수도 있어요
- 🐢 **거북이 섬**: 아기·어른 거북이 100마리. 머리 위에 최대 6마리까지 쌓아 안고, 안은 채로 배에 타서 거북이 상자에 한 번에 넣어요. 바다에 빠진 거북이는 헤엄쳐 배를 따라와요
- 🧗 **돛대 오르기**: 꼭대기에 오르면 지도가 훨씬 멀리까지 밝혀져요
- 🏝️ **모투누이 마을**: 음식 가판대, 모닥불 요리, 코코넛 야자수, 숨겨진 동굴, 족장의 돌탑, 푸아와 마을 사람들
- 🗺️ **지도**: 가 본 곳이 밝혀지는 지도와 목표 표시
- 🪝 **마우이**: 갈고리를 되찾으면 매로 변신해 날고, 갈고리로 적을 내려치기 (Tab으로 조종 전환)
- 🥥 **카카모라 해적**, 🦀 **타마토아**, 🌋 **테 카 → 테 피티**
- 🦇 **2장**: 선원 모으기, 거대 조개, 마탕기, 날로의 폭풍, 모투페투 끌어올리기

자세한 기획과 조작법은 [docs/GAME_DESIGN.md](docs/GAME_DESIGN.md)를 보세요.

## 폴더 구조

```
index.html, style.css      화면과 HUD
server.js                  정적 서버
src/net/                   2인 플레이 (연결: session.js, 동기화: sync.js)
tools/peer-server.cjs      (선택) 같은 Wi-Fi 전용 2인 연결 도우미
vendor/                    Three.js와 GLB 로더 (오프라인 동작을 위해 포함)
assets/models/             게임이 쓰는 캐릭터 3D 모델 (모아나, 마우이, 헤이헤이 · 압축본)
assets/source/             처음 올린 원본 모델 (배포에는 포함 안 됨)
tools/compress-models.mjs  원본 모델 압축 스크립트 (npm run compress-models)
src/
  main.js, game.js         시작점, 게임 본체(루프·상호작용·AI·저장)
  config.js                섬 위치와 지형 정의
  world/                   지형, 바다 셰이더, 하늘, 식생, 모투누이 마을, 특별한 장소
  entities/                배, 캐릭터, 헤이헤이·푸아, 바다 구조, 카카모라, 랄로타이, 테 카, 2장
  systems/                 입력, 카메라, 퀘스트·대사, 효과, 전투, 소리
  ui/                      HUD, 대화창, 지도
docs/GAME_DESIGN.md        기획서
```

## 배경 음악

신나는 항해 곡을 새로 만들어 넣었습니다. 마을, 항해, 밤, 전투에 따라 분위기가 바뀝니다. 내 음악으로 바꾸는 방법은 `assets/music/README.md`를 보세요.

## 캐릭터 3D 모델 바꾸기

`assets/README.md`를 보세요. 원본을 `assets/source/`에 넣고 `npm install && npm run compress-models`를 실행하면 됩니다.

## 저작권

개인·비상업용 팬 게임입니다. 캐릭터 GLB 모델(Meshy AI로 생성)을 제외한 3D 모델, 텍스처, 소리, 음악, 대사는 코드로 새로 만들었고 영화의 실제 이미지·영상·노래 가사는 포함하지 않습니다. 모아나 관련 인물과 세계관의 권리는 원저작권자에게 있습니다.
