# 🌊 모아나의 항해 (Moana Voyage)

영화 〈모아나〉와 〈모아나 2〉를 바탕으로 만든 **비상업용 3D 항해 팬 게임**입니다.
모아나가 되어 배를 몰고 넓은 바다를 건너, 마우이와 함께 테 피티의 심장을 돌려주세요.
아이패드(터치)와 컴퓨터(키보드) 모두에서 브라우저로 바로 즐길 수 있습니다.

![icon](icons/icon.svg)

## 🎮 웹에서 바로 하기

설치 없이 아이패드나 컴퓨터 브라우저에서 이 주소를 열면 됩니다.

**https://merrypapa.github.io/moana-voyage/**

`main` 브랜치에 푸시하면 자동으로 다시 배포됩니다.

## 내 컴퓨터에서 실행하기

Node.js 18 이상이 필요합니다. 설치할 패키지는 없습니다.

```bash
npm start
```

- 컴퓨터: 브라우저에서 `http://localhost:8080`
- 아이패드: 같은 Wi-Fi에서 터미널에 표시되는 `http://192.168.x.x:8080` 주소로 접속
  - Safari 공유 버튼 → "홈 화면에 추가"를 누르면 전체 화면 앱처럼 쓸 수 있어요.

빌드 과정이 없는 정적 웹 앱이라 GitHub Pages 같은 정적 호스팅에 그대로 올려도 동작합니다.

## 무엇을 할 수 있나요?

- ⛵ **항해**: 배 뒤쪽의 키를 잡고 돛을 올려 바다를 누비기 (바람을 등지면 더 빨라요)
- 🌊 **바다가 구해줘요**: 물에 빠지면 바다가 물기둥으로 들어 올려 배 위에 내려줘요
- 🐔 **헤이헤이**: 배 위의 네모 상자에 스스로 들어갔다 나왔다 해요. 안아서 넣고 꺼낼 수도 있어요
- 🧗 **돛대 오르기**: 꼭대기에 오르면 지도가 훨씬 멀리까지 밝혀져요
- 🏝️ **모투누이 마을**: 음식 가판대, 모닥불 요리, 코코넛 야자수, 숨겨진 동굴, 족장의 돌탑, 푸아와 마을 사람들
- 🗺️ **지도**: 가 본 곳이 밝혀지는 지도와 목표 표시
- 🪝 **마우이**: 갈고리를 되찾으면 매로 변신해 날고, 갈고리로 적을 내려치기 (Tab으로 조종 전환)
- 🥥 **카카모라 해적**, 🦀 **타마토아**, 🌋 **테 카 → 테 피티**
- 🦇 **2장**: 선원 모으기, 거대 조개, 마탕기, 날로의 폭풍, 모투페투 끌어올리기

자세한 기획과 조작법은 [docs/GAME_DESIGN.md](docs/GAME_DESIGN.md)를 보세요.

## 폴더 구조

```
index.html, style.css      화면과 HUD
server.js                  정적 서버 (나중에 2인 플레이 중계 추가 예정)
vendor/                    Three.js (오프라인 동작을 위해 포함)
src/
  main.js, game.js         시작점, 게임 본체(루프·상호작용·AI·저장)
  config.js                섬 위치와 지형 정의
  world/                   지형, 바다 셰이더, 하늘, 식생, 모투누이 마을, 특별한 장소
  entities/                배, 캐릭터, 헤이헤이·푸아, 바다 구조, 카카모라, 랄로타이, 테 카, 2장
  systems/                 입력, 카메라, 퀘스트·대사, 효과, 전투, 소리
  ui/                      HUD, 대화창, 지도
docs/GAME_DESIGN.md        기획서
```

## 저작권

개인·비상업용 팬 게임입니다. 모든 3D 모델, 텍스처, 소리, 음악, 대사는 코드로 새로 만들었고 영화의 실제 이미지·영상·노래 가사는 포함하지 않습니다. 모아나 관련 인물과 세계관의 권리는 원저작권자에게 있습니다.
