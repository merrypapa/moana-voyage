# 모아나의 항해 — 게임 기획서

> 비상업용 팬 게임. 영화 〈모아나〉(2016)와 〈모아나 2〉(2024)의 인물과 이야기를 바탕으로 만든 3D 항해 모험 게임입니다.

## 1. 한눈에 보기

| 항목 | 내용 |
| --- | --- |
| 장르 | 3D 오픈 월드 항해 모험 (어린이도 즐길 수 있는 난이도) |
| 플랫폼 | 웹 브라우저. 아이패드(Safari, 터치) · 컴퓨터(키보드+마우스) |
| 플레이 인원 | 1인 (모아나 ↔ 마우이 전환). 2인 온라인 협동은 다음 단계 |
| 목표 | 테 피티의 심장을 돌려주고(1장), 가라앉은 섬 모투페투를 되살리기(2장) |
| 기술 | Three.js(로우폴리 3D), 빌드 과정 없음, 그림/소리 모두 코드로 생성 |

## 2. 핵심 재미

1. **내 배로 넓은 바다를 항해한다.** 돛을 올리고 내리며 키를 잡고, 바람을 등지면 더 빨라진다. 지도는 약 10km × 10km.
2. **살아 있는 바다가 모아나를 지켜준다.** 물에 빠지면 바다가 물기둥으로 모아나를 들어 올려 배 위에 내려준다. 헤이헤이도, 마우이도 구해 준다(마우이는 던져서).
3. **귀여운 동료들과 함께한다.** 헤이헤이는 배 위를 멍하게 돌아다니다 네모 상자에 들어갔다 나왔다 하고, 가끔 바다에 빠진다. 푸아는 마을에서 모아나를 졸졸 따라다닌다.
4. **마우이로 변신한다.** 갈고리를 되찾으면 매로 변신해 하늘을 날고, 갈고리로 적을 내려치고, 섬을 끌어올린다.

## 3. 등장인물

| 인물 | 역할 | 게임 속 모습 |
| --- | --- | --- |
| 모아나 | 주인공, 항해자 | 걷기·달리기·점프, 키 잡기, 돛대/절벽 오르기, 코코넛 던지기, 노 휘두르기, 헤이헤이/푸아 안기, 심장 돌려주기 |
| 마우이 | 반신, 두 번째 주인공 | 갈고리 없음 → 주먹만. 갈고리를 찾으면 매 변신(비행), 갈고리 내려치기, 모투페투 끌어올리기 |
| 헤이헤이 | 닭 | 배 위를 배회, 스스로 상자에 들어갔다 나옴, 가끔 바다에 빠짐(바다가 구해줌), 카카모라의 표적 |
| 푸아 | 돼지 | 마을에서 모아나를 따라다님, 안아서 배에 태울 수도 있음(배 밖으로는 안 나감) |
| 탈라 할머니 | 길잡이 | 해변에서 춤추며 비밀을 알려줌. 항해 중에는 빛나는 가오리 영혼이 되어 목표 방향으로 헤엄침 |
| 투이 족장, 시나 | 부모님 | 마을 퀘스트 |
| 카카모라 | 코코넛 해적 | 해적선이 쫓아와 갑판에 올라타 헤이헤이를 훔쳐 감. 2장에서는 친구(코코넛 선물) |
| 타마토아 | 반짝이 게 | 랄로타이의 보스. 갈고리를 등껍질에 붙이고 있음 |
| 테 카 / 테 피티 | 용암 악마 / 생명의 여신 | 1장 최종. 심장을 돌려주면 테 피티로 돌아옴 |
| 모니, 로토, 켈레, 시메아 | 2장 선원과 동생 | 로토는 배 속도 업그레이드, 켈레는 음식 보급 |
| 마탕기 | 박쥐 날개 반신 | 빛나는 꽃 퀘스트, 폭풍 공략법 |
| 날로 | 폭풍의 신 | 모투페투 주변 번개 폭풍 |

## 4. 월드 (지도)

좌표 1단위 = 1m. 지도 범위 ±5,200m. 북쪽이 위.

| 장소 | 위치 | 내용 |
| --- | --- | --- |
| 모투누이 | 중앙 | 고향 마을. 산, 폭포, 숨겨진 동굴, 암초(남쪽이 열려 있음) |
| 마우이의 섬 | 북동 | 모래섬, 날짜를 센 동굴, 마우이 석상 |
| 카카모라의 바다 | 동 | 해적선 습격 구역 |
| 괴물의 섬 | 동북동 | 150m 절벽 섬. 꼭대기 구멍 → 랄로타이(지하 세계) |
| 테 피티 + 용암 방벽 | 남동쪽 끝 | 나선 모양 섬, 용암 섬 11개가 둘러쌈 |
| 거대 조개의 바다 | 북서 | 소용돌이 |
| 마탕기의 섬 | 북서 | 어두운 섬, 박쥐 날개 바위, 빛나는 덩굴과 꽃 |
| 모투페투 | 북서쪽 끝 | 바닷속에 가라앉은 전설의 섬, 날로의 폭풍 |
| 작은 섬 10여 개 | 곳곳 | 거북이 섬, 야자수 섬, 산호 섬, 쌍둥이 섬, 새들의 섬, 시든 섬 등 |

- 어둠(저주)에 걸린 섬들은 잿빛이고 야자수가 말라 있다. 테 피티를 되살리면 모두 초록으로 돌아온다.
- 지도(M)는 가 본 곳만 밝혀진다. 돛대 꼭대기에 오르면 훨씬 멀리 보인다(1.1km).

## 5. 마을 (모투누이)

- **음식 가판대 4곳**: 바나나, 타로, 생선, 빵나무 열매를 가져갈 수 있다.
- **모닥불**: 타로 + 생선 → "잔치 한 상"(배고픔 크게 회복, 체력 모두 회복).
- **코코넛 야자수 12그루**: 흔들면 코코넛이 떨어진다. 45초 뒤 다시 열린다. 코코넛은 먹거나 카카모라에게 던진다.
- **족장의 돌탑**: 산꼭대기에 돌을 올리는 전통.
- **숨겨진 동굴**: 폭포 옆, 조상들의 배와 벽화, 통나무 북.
- **마을 사람 10명**: 돌아다니며 이야기, 테 피티 복원 후에는 대사가 바뀜.

## 6. 이야기 진행

### 1장 — 테 피티의 심장
1. 투이 족장과 이야기 → 코코넛 3개 모으기(세 번째는 까맣게 썩음 = 어둠의 징조)
2. 탈라 할머니 → 숨겨진 동굴에서 북 치기("우리는 항해자였어!") → 배가 해변에 준비됨
3. 탈라 할머니에게 심장을 받음(목걸이 로켓)
4. 배를 타고 암초 밖으로 → **헤이헤이 밀항 이벤트**(상자 속에서 등장)
5. 마우이의 섬에서 마우이 합류(갈고리 없음)
6. 카카모라 해적선 4척 격파(들이받기, 코코넛, 노, 마우이 주먹). 헤이헤이를 상자에 숨기면 안전
7. 괴물의 섬 절벽 오르기 → 랄로타이로 뛰어들기
8. 빛나는 이끼로 미끼를 만들어 타마토아가 한눈팔 때 갈고리 되찾기 → 간헐천으로 귀환
9. 마우이로 바꿔 매로 변신해 하늘 높이 날기
10. 테 피티로 항해. 테 카가 불덩이를 던짐(빨간 원 = 떨어질 곳). 매가 된 마우이가 가까이 날면 테 카가 마우이를 노림
11. 방벽 안으로 들어가면 모아나가 진실을 깨닫고, 테 카가 다가와 무릎 꿇음 → 심장 돌려주기 → 테 피티 부활, 모든 섬 복원
12. 모투누이로 귀환 → 1장 완료

### 2장 — 모투페투
1. 탈라 할머니의 부름(조상 타우타이 바사, 가라앉은 섬 모투페투)
2. 선원 모으기: 모니, 로토(배 속도 +35%), 켈레(음식)
3. 거대 조개의 소용돌이 탈출(돛을 활짝, 마우이 갈고리로 조개 기절)
4. 마탕기 만나기 → 빛나는 꽃 3송이 → 폭풍 공략법
5. 날로의 폭풍: 큰 파도, 비, 노란 원 = 번개 떨어질 곳
6. 폭풍의 눈에서 마우이가 갈고리로 5번 끌어올리기 → 모투페투 부상, 폭풍이 걷힘
7. 모투페투에 발 딛기 → 엔딩 → 자유 항해

## 9. 2인 협동 플레이 계획 (다음 단계)

한 명은 모아나, 한 명은 마우이. 두 대의 기기(아이패드 2대, 또는 아이패드 + 컴퓨터)로 같은 바다에서 함께 논다.

**지금 준비된 구조**
- 모든 캐릭터는 "명령(PlayerCommand)"으로 움직인다(`src/systems/input.js`의 `emptyCommand`). 로컬 입력, AI, 원격 입력이 모두 같은 형태다.
- 캐릭터마다 `controlledBy` 값이 있다: `local` / `ai` / (추가 예정) `remote`.
- 지금은 Tab으로 1인이 둘을 번갈아 조종하고, 조종하지 않는 쪽은 AI가 따라온다.

**구현 방법 (호스트 방식)**
1. `server.js`에 WebSocket 중계를 추가한다(`ws` 패키지). 방 코드 4자리로 입장.
2. 먼저 들어온 사람(호스트)의 브라우저가 게임 전체를 계산한다. 배, 헤이헤이, 적, 퀘스트 모두.
3. 게스트는 자기 명령(이동, 버튼, 카메라 방향)을 초당 30번 보낸다. 호스트는 그 명령을 마우이(`controlledBy = 'remote'`)에 넣는다.
4. 호스트는 초당 15~20번 상태(캐릭터·배·적 위치, 체력, 퀘스트 단계, 대화)를 게스트에게 보낸다. 게스트는 받은 상태 사이를 부드럽게 보간해 그린다.
5. 대화창은 두 화면에 동시에 뜨고, 누구나 넘길 수 있다.
6. 같은 Wi-Fi에서 `npm start` 후 표시되는 주소로 두 기기가 접속한다. 인터넷 너머로 하려면 서버를 호스팅하거나 터널을 쓴다.

**협동 전용 아이디어**
- 테 카 전투: 마우이가 매로 날아 주의를 끄는 동안 모아나가 방벽을 통과(이미 동작함)
- 모투페투 끌어올리기: 모아나가 배로 폭풍의 눈을 지키고 마우이가 갈고리질
- 카카모라: 한 명은 키, 한 명은 갑판 방어

## 10. 저작권 관련 메모

이 게임은 개인·비상업용 팬 게임입니다. 인물 이름과 이야기 흐름은 영화를 따르지만, 3D 모델·텍스처·효과음·음악·대사는 모두 이 프로젝트에서 새로 만든 것이며 영화의 실제 이미지, 영상, 노래 가사는 포함하지 않습니다. 외부 공개나 배포 전에는 권리자의 팬 콘텐츠 정책을 확인하세요.
