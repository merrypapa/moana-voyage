# 캐릭터 3D 모델

| 폴더 | 내용 | 게임에서 사용 |
| --- | --- | --- |
| `models/` | 게임이 불러오는 압축된 모델 | ✅ (웹 배포에 포함) |
| `source/` | 처음 올린 원본 모델 (Meshy AI) | ❌ (압축 재료로만 보관) |

| 파일 | 캐릭터 | 원본 | 압축 후 |
| --- | --- | --- | --- |
| `moana.glb` | 모아나 | 9.0MB | 0.77MB |
| `maui.glb` | 마우이 | 8.7MB | 0.89MB |
| `heihei.glb` | 헤이헤이 | 7.5MB | 0.53MB |

## 모델을 바꾸거나 추가하려면

1. 원본 GLB를 `assets/source/`에 올립니다. 파일 이름은 `moana.glb`, `maui.glb`, `heihei.glb` 중 하나로 합니다.
2. 압축합니다.
   ```bash
   npm install
   npm run compress-models
   ```
3. 만들어진 `assets/models/`의 파일을 커밋하고 `main`에 푸시하면 웹 게임에 반영됩니다.

압축 내용: 텍스처를 WebP로 바꾸고 크기를 줄입니다(색상·노멀 1024px, 금속·거칠기 512px). 폴리곤 수는 그대로입니다.

## 모델 규칙

- 서 있는 자세, 정면이 +Z 방향 (Meshy 기본값 그대로면 됩니다)
- 크기는 자동으로 맞춥니다: 모아나 1.65m, 마우이 2.6m, 헤이헤이 0.7m (`src/entities/glbModels.js`)
- 지금 모델은 뼈대(애니메이션)가 없어 몸 전체가 뒤뚱거리는 방식으로 걷습니다. 뼈대와 걷기 애니메이션이 있는 모델을 올리면 연결할 수 있습니다.
- 파일이 없거나 불러오지 못하면 게임은 기본 도형 모델로 동작합니다.
