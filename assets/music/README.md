# 배경 음악

기본 배경 음악은 이 게임을 위해 새로 만든 폴리네시아풍 곡입니다(`src/systems/music.js`).
통나무 북, 우쿨렐레, 베이스, 멜로디, "헤이!" 합창으로 이루어져 있고, 상황에 따라 분위기가 바뀝니다.

| 상황 | 분위기 |
| --- | --- |
| 마을 (낮) | 가볍고 밝게 |
| 항해 중 | 모든 악기가 신나게 + 합창 |
| 밤 | 잔잔한 우쿨렐레 |
| 카카모라, 타마토아, 테 카, 폭풍, 거대 조개 | 긴박한 단조 + 북 |

## 내 음악으로 바꾸기

이 폴더에 `bgm.mp3` 파일을 넣고 `main`에 푸시하면, 게임이 새로 만든 곡 대신 그 파일을 반복해서 틉니다.
파일을 지우면 다시 기본 곡으로 돌아갑니다.

⚠️ 이 저장소와 웹 게임은 공개되어 있어서, 여기에 넣은 음악 파일은 누구나 내려받을 수 있습니다.
영화 음악처럼 저작권이 있는 곡은 넣지 말고, 직접 만들었거나 사용 허락을 받은 곡(무료 공개 음원 등)을 사용하세요.
